# Política de seguridad

## Reportar una vulnerabilidad

Si encuentras un problema de seguridad en este proyecto, **no abras un issue público**.

Repórtalo de forma privada desde la pestaña **Security → Report a vulnerability** de este repositorio. Incluye, si puedes:

- Qué encontraste y dónde (archivo o URL).
- Los pasos para reproducirlo.
- El impacto que crees que tiene.

Responderé lo antes posible y te mantendré al tanto de la corrección.

## Alcance

Explorer for Laravel es un sitio estático (HTML, CSS y JavaScript) sin backend, sin dependencias y sin datos de usuarios. Los reportes más relevantes son los que afecten a quien abre la página, por ejemplo inyección de scripts (XSS).

## Contribuciones

Solo el mantenedor del repositorio puede fusionar cambios en `main`. Las contribuciones se reciben por pull request desde un fork y se revisan antes de aceptarse.
